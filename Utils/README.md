# Unity utility scripts

This folder includes a variety of scripts to extend the basic Unity API and make some common coding patterns clearer. 

To use this code, copy this folder into your Unity project. 

All of these classes are implemented in the `WordsOnPlay.Utils` namespace, so you will need to include the header `using WordsOnPlay.Utils` in any C# file that uses this functionality 

## Extensions

These classes add extra methods to standard Unity classes:
* BoxColliderExtensions - Extends the BoxCollider class to add methods to test whether the box collider is currently occupied.
* LayerMaskExtensions - Extends the LayerMask class to check if a game object matches the layermask.
* RectExtensions - Extends the Rect class to add several shortcuts.
* Vector2Extensions - Extends the Vector2 class to add Rotate and IsOnLeft methods
* Vector3Extensions - Extends the Vector3 class to several shortcuts.

## Components

These classes implement components to add functionality to GameObjects
* DoNotDestroy - Tag the GameObject with DontDestroyOnLoad()
* LogFile - A simple implementation of a spreadsheet-style logfile for game analytics
* Note - Adds a text field to game object in the Inspector for notes

## Value types

These classes implemnt comment parameter types
* Range - Represents a range from a min to max value
* Timer - Implements a basic count-down timer.
 
## QA

These classes are intended for QA purposes
* FPSLimiter - Force the Unity editor to run at a specific framerate
* RNG - Adds a wrapper to System.Random to allow you to specify the numbers generated by the RNG

## Coroutines

These utilities are more advanced, mostly dealing with Coroutines, and should be used with care:

* InlineCR - Write short co-routines inline using lambda expressions
* AnimationCurveExtensions - Adds a function to run an animation curve as a coroutine
* MonoBehaviour - Addeds shortcuts to create coroutines.
